Política de privacidad de donna-personal

Última actualización: 7 de noviembre de 2026.

donna-personal es una aplicación de uso privado. Solo la usa su propietario, con su propia cuenta de Google.

Qué datos usa

  • Gmail (permiso gmail.modify): leer mensajes, aplicar etiquetas y crear borradores.
  • Google Calendar (permiso calendar): consultar y gestionar eventos.

Cómo los usa

Solo para las tareas que pide el propietario: ordenar el correo, preparar respuestas y llevar su calendario. Para hacerlas, el contenido necesario se procesa con el modelo de IA que usa el asistente (Claude, de Anthropic). No se envía nada en nombre del propietario sin su aprobación.

Dónde se guardan

La aplicación funciona en el ordenador del propietario. El acceso concedido por Google se guarda en el llavero de ese ordenador. No hay servidor propio ni base de datos con los datos de Gmail o Calendar.

Con quién se comparten

Con nadie, salvo el procesamiento por el modelo de IA descrito arriba. No se venden ni se usan para publicidad. El uso de los datos recibidos de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo retirar el acceso

En cualquier momento, desde myaccount.google.com/permissions.
